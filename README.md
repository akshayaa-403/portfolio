## Local Setup

To run and preview this project locally:

1. Clone the repository:

```bash
git clone https://github.com/akshayaa-403/portfolio.git
cd portfolio
```

2. Open `index.html` in your browser or run a local static file server:

```bash
# Using Python 3
python3 -m http.server 8000
```

3. Visit `http://localhost:8000` in your browser.
